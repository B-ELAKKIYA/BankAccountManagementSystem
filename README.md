Bank Account Management System (BAMS)

A simple Java-based Bank Account Management System that allows customers to:
Validate Customer
Deposit Money
Withdraw Money
View Transaction History
Handle Custom Exceptions
This project is built using Core Java (OOP + Collections + Exception Handling).

Project Overview
The system simulates basic banking operations using:
ArrayList for data storage
Object-Oriented Programming concepts
Custom Exception Handling
Layered Architecture

Concepts Used
Classes & Objects
Constructor & Encapsulation
ArrayList Collection
Custom Exceptions
Exception Handling (try-catch)
Date Handling
